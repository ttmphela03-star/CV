* **kaggle_irrigation_comp_model.ipynb** - Two classification models used to soley focus on the accuracy of predicting the irrigation need of a crop. Python code also includes my understanding of data wrangling and feature engineering.

* **neural_network.ipynb** - A classifcation neural network built to identify whether or not an F1 driver is likely to stop at the next pit stop. Show casing my understanding of the latest trends within AI and machine learning. 

* **MachineLearningDocument.pdf** - A digital notebook I've made to update my understanding behind the machine learning models I use. In the hope of one day publishing to help prospective data scientists navigate through the world of machine learning.(Incomplete) 

* **F1PitStop_KaggleCompetition** - A folder from a recent kaggle compeition. The folder contains 4 models I produced with the aim of maximizing the AUC score of predictions. The catboost.ipynb is a normal catboost model. The xgboost.ipynb is a normal xgboost model. The race_models.ipynb is my favourite model that splits the data depending on the different categorical features and trains separate models as base models. Combines the predictions to form meta-data for the meta-model to make final predictions. This model highlights my creativity. I tried numerous means such as taking the average of predicitons. Different meta-models and pca encoding. The final model is stacking_classifier.ipynb, a normal stacking model that I used to explore the capabilities of hyperparameters such as depth, iteration size and learning rate. The different models used different methods of learning such as capturing deeping connections within data against more vast shallow connections. Overall best result: **AUC - 0.95047**.
